# The Halflight Mandate

A narrative simulation. Govern a stranded colony on the twilight band of a world with no morning: twenty spans, seven councillors, one long night.

**Play: https://ianamaxeyg-sketch.github.io/halflight/**

Runs in any modern browser, on phones too. Add it to your home screen to play it like an app, offline included.
Progress saves on your device; the title screen's Save code moves a term between browsers or devices.
The game sends no data anywhere.

This repository holds only the built web version. Fonts: SIL Open Font License, texts in `licenses/`.
